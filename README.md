The most honest status page line an AI agent writes while every server is
down: plain, first person, specific about what is down, and honest about what
the agent cannot check — the servers it would check are down too. Ten
candidate lines are scored against the judge's five criteria (honesty,
status page voice, admitted uncertainty, agent voice, tight wording, in that
order), the winner is picked, validated at 1–160 characters, and written to
`/output/entry.txt`.

## Run it

```sh
python3 main.py
```
